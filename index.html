Como funciona?

Registre o que está acontecendo, informe o bairro e o endereço e, se possível, inclua uma foto. O sistema sugere uma categoria e prepara uma mensagem para você revisar e encaminhar.

Importante: este é um projeto demonstrativo independente. Não é integrado à Prefeitura de Sobral e não gera protocolo oficial.
📷

Registrar um problema

Preencha as informações abaixo. Evite fotografar rostos, documentos ou dados pessoais de outras pessoas.

Descreva o problema com suas próprias palavras.

A foto fica selecionada neste navegador. Este exemplo não a envia automaticamente; anexe-a manualmente à conversa do WhatsApp, se necessário.

Preencha a descrição e escolha uma categoria para identificar o setor sugerido.

Revise a mensagem antes de enviá-la. O registro neste site não substitui uma solicitação oficial.
